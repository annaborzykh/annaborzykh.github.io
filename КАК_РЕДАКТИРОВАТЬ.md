# Как самостоятельно редактировать портфолио

Это исходники сайта на React/Next.js. Главная страница записана в формате JSX — он почти такой же, как HTML, но позволяет собирать повторяющиеся карточки из списков.

## Что где находится

- `app/page.tsx` — все основные тексты, карточки проектов, изображения, видео, PDF и контакты.
- `app/globals.css` — цвета, размеры, отступы, сетки и адаптация под телефон.
- `app/layout.tsx` — название вкладки браузера и описание сайта.
- `public/work/` — изображения и видео проектов.
- `public/decks/` — PDF-презентации.

В этих трёх файлах уже стоят русские комментарии с пометками, что именно редактируется.

## Самые важные правки перед публикацией

Открой `app/page.tsx` и найди через `Ctrl + F`:

1. `Имя Фамилия` — имя в шапке и внизу страницы.
2. `черновик` — можно заменить или удалить весь фрагмент `<span>черновик</span>`.
3. `[Название компании]` и `[период работы]` — данные в блоке опыта.
4. `[ссылка]`, `[почта]`, `[ссылка на резюме]` — контакты.

Затем открой `app/layout.tsx` и замени имя в `title`.

## Как менять обычный текст

Текст находится между тегами. Например:

```tsx
<h3>Старое название проекта</h3>
```

Можно заменить на:

```tsx
<h3>Новое название проекта</h3>
```

Не удаляй угловые скобки у тегов и закрывающую часть вроде `</h3>`.

## Как заменить изображение

1. Положи новый файл в подходящую папку внутри `public/work/`.
2. В `app/page.tsx` найди нужное изображение.
3. Замени только путь в `src`.

Пример:

```tsx
src="/work/merch/hoodie-mockup.webp"
```

Путь начинается с `/`, но папка `public` в нём не пишется.

Лучше использовать латинские имена файлов без пробелов: `new-project-cover.webp`.

## Как заменить видео

Положи MP4 в `public/work/` и поменяй путь в строке:

```tsx
<source src="/work/merch/fashion-film.mp4" type="video/mp4" />
```

Картинка до запуска видео задаётся через `poster="..."`.

## Как заменить PDF-презентацию

Положи PDF в `public/decks/` и замени ссылку:

```tsx
href="/decks/vk-ai-merch.pdf"
```

Превью PDF на карточке — это отдельные изображения в `public/work/presentations/`.

## Как изменить цвета

Открой начало `app/globals.css`. Основные цвета собраны в блоке `:root`:

```css
--plum: #43204f;
--violet: #8c4aa5;
--lilac: #eee9ff;
--mint: #beefd8;
```

Можно вставлять свои HEX-цвета, не меняя названия переменных.

## Как запустить сайт на компьютере

Понадобится Node.js 22 или новее.

1. Распакуй ZIP.
2. Открой папку в Visual Studio Code.
3. Открой терминал в этой папке.
4. Один раз установи зависимости:

```bash
npm install
```

5. На Windows запусти сайт так:

```bash

```

На macOS или Linux также можно использовать `npm run dev`.

6. Открой адрес, который появится в терминале. Обычно это `http://localhost:3000` или `http://localhost:5173`.

После правки файла просто сохрани его через `Ctrl + S` — страница обновится автоматически.

## Как проверить перед публикацией

На Windows в терминале выполни:

```bash
npx vinext build
```

На macOS или Linux можно использовать `npm run build`.

Если команда завершилась без ошибки, проект собирается нормально.

## Что не нужно редактировать без необходимости

- `.openai/hosting.json`
- `worker/`
- `scripts/`
- `build/`
- `vite.config.ts`
- `next.config.ts`
- `package.json` и `package-lock.json`

Для обычной замены контента достаточно папок `app/` и `public/`.
